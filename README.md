# PythonClass

Учебный интерактивный сайт по основам программирования на Python для 8 класса.

## Возможности

- Теория и примеры шести ключевых конструкций Python: переменные, циклы for и while, условия if, списки и функции.
- Поиск по материалам, раскрывающиеся примеры кода и отметки «Лайк».
- Интерактивный Python-калькулятор с арифметическими операциями и таблицей результатов.
- Тест для самопроверки из восьми вопросов по основам Python.
- Светлая и тёмная тема с салатовой цветовой гаммой, адаптивное оформление.

## Файлы проекта

- `index.html` — структура и содержание страниц.
- `style.css` — оформление и адаптивная вёрстка с салатовой цветовой схемой.
- `script.js` — интерактивные функции: калькулятор, тест, поиск, темы.

## Запуск

Сайт работает непосредственно в браузере. Для запуска достаточно открыть `index.html`.

## Технологии

- HTML5 — семантическая разметка с aria-атрибутами
- CSS3 — CSS-переменные, Flexbox, Grid, адаптивный дизайн
- JavaScript (ES5+) — без внешних библиотек

## Содержание курса

### Основы
- Переменные и типы данных (int, float, str, list)
- Синтаксис и отступы
- Комментарии

### Конструкции
1. **Переменные** — хранение данных
2. **Цикл for** — повтор по элементам
3. **Условие if** — проверка условий
4. **Списки** — коллекции элементов
5. **Функции** — блоки кода
6. **Цикл while** — повтор по условию

### Практика
- Интерактивный калькулятор с операциями: +, −, ×, /, **, %
- Таблица результатов для разных значений переменных
- Живые примеры кода

### Тест
8 вопросов с объяснениями:
- Арифметические операции
- Создание переменных
- Типы данных
- Циклы и функции
- Синтаксис Python
