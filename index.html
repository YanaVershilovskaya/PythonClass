Что такое Python?

04 / Полезно запомнить

Маленькая шпаргалка

Три важных правила, которые помогут тебе писать правильный Python-код.

01

Отступы обязательны

Python использует отступы для обозначения блоков кода. Один уровень = 4 пробела. Без отступов код не заработает.

if x > 0:
    print("Да")
02

Названия переменных

Используй понятные имена: age, name, count. Не начинай с цифры. Пробелы запрещены — используй underscore_style.

user_name = "Иван"
03

Комментарии в коде

Комментарии начинаются с #. Python их игнорирует. Используй для пояснений.

# Это комментарий
